# World Cup 2026 iOS Widget

![iOS](https://img.shields.io/badge/iOS-000000?style=for-the-badge&logo=ios&logoColor=white)
![Widget](https://img.shields.io/badge/Widget-Scriptable-blue?style=for-the-badge)
![World Cup 2026](https://img.shields.io/badge/World_Cup-2026-green?style=for-the-badge)

Ένα widget για το iOS που παρακολουθεί το Παγκόσμιο Κύπελλο FIFA 2026. Προσφέρει ζωντανές ενημερώσεις για τους επερχόμενους αγώνες, την πρόοδο του τουρνουά και τα ζωντανά σκορ, απευθείας στην οθόνη του κινητού σας.

## Δυνατότητες
- **Ζωντανά Σκορ**: Αυτόματη ενημέρωση για τους αγώνες που βρίσκονται σε εξέλιξη.
- **Φάση Τουρνουά**: Εντοπίζει την τρέχουσα φάση (Φάση Ομίλων, Φάση των 32, Τελικός, κλπ.).
- **Προσαρμόσιμο Μέγεθος**: Υποστηρίζει Μικρό, Μεσαίο και Μεγάλο μέγεθος widget στο iOS.
- **Μινιμαλιστικός Σχεδιασμός**: Όμορφο, dark-mode βελτιστοποιημένο design.

## Οδηγίες Εγκατάστασης

Για να προσθέσετε το widget στο κινητό σας, ακολουθήστε τα παρακάτω απλά βήματα:

### 1. Κατέβασμα Εφαρμογής
Κατεβάστε τη δωρεάν εφαρμογή **[Scriptable](https://apps.apple.com/app/scriptable/id1405459188)** από το App Store.

### 2. Προσθήκη του Script
1. Ανοίξτε την εφαρμογή **Scriptable** και πατήστε το εικονίδιο **`+`** πάνω δεξιά για να δημιουργήσετε ένα νέο script.
2. Αντιγράψτε όλο το περιεχόμενο του αρχείου `widget.js` και επικολλήστε το στο νέο script.
3. Πατήστε στον τίτλο (στο πάνω μέρος) και μετονομάστε το σε **WC26**.
4. Πατήστε **Done** για να το αποθηκεύσετε.

### 3. Προσθήκη στην Αρχική Οθόνη
1. Κρατήστε πατημένο το δάχτυλό σας σε έναν κενό χώρο στην αρχική οθόνη του iPhone σας μέχρι να αρχίσουν να κουνιούνται τα εικονίδια.
2. Πατήστε το **`+`** στην πάνω αριστερή γωνία.
3. Στην αναζήτηση, βρείτε και επιλέξτε το **Scriptable**.
4. Διαλέξτε το μέγεθος του widget που προτιμάτε (συνιστάται το Μεσαίο ή Μεγάλο) και πατήστε **Προσθήκη widget**.
5. Πατήστε πάνω στο widget που μόλις προστέθηκε στην οθόνη σας.
6. Στο πεδίο **Script**, επιλέξτε το **WC26**.
7. Πατήστε οπουδήποτε αλλού στην οθόνη για να ολοκληρωθεί η ρύθμιση.

Αυτό ήταν! Το widget σας είναι έτοιμο και θα ανανεώνεται αυτόματα.
